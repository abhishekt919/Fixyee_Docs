# Create a Work Order

Work Orders help you track repairs, maintenance work, inspection issues, PM services, parts, labor, mechanic time, and external repair details.

## In this article

- Create a manual Work Order
- Create a Work Order from a defect
- Create a Work Order from an inspection
- Create a Work Order from PM service
- Create an External Work Order using AI Scan
- Create an External Work Order from forwarded email
- Add parts, labor, misc charges, and mechanic time
- Delete a Work Order

---

## Create a manual Work Order

Use manual creation when you want to create a Work Order directly from the Work Orders page.

<Tabs>
  <TabItem value="web" label="Web" default>

1. Navigate to **Work Orders**.
2. Click **Create Work Order**.
3. Select the customer and asset.
4. If the work is planned for a future date, select the future **Date Created**.
5. Add tasks and assign mechanics.
6. Click **Save**.

  </TabItem>

  <TabItem value="mobile" label="Mobile">

1. Open **Work Orders** from the mobile app.
2. Tap the **+** icon.
3. Select the customer and asset.
4. Add task details and mechanics.
5. Tap **Save**.

  </TabItem>
</Tabs>

:::tip 
<span style={{ color: '#2563eb', fontWeight: 'bold' }}>
Future Work Orders
</span>
To create a Work Order for a future date, select a future **Date Created** while creating the Work Order.
:::

## Create a Work Order from a defect

Use this option when a reported defect needs repair work.

1. Navigate to **Defects**.
2. Open the defect.
3. Click **Create Work Order**.
4. Review the defect details.
5. Add tasks, parts, labor, or mechanic details if required.
6. Click **Save**.

:::info
The defect will be linked with the Work Order for tracking and resolution.
:::

---

## Create a Work Order from an inspection

A Work Order can be created from a failed inspection item.

1. Navigate to **Inspections**.
2. Open the inspection.
3. Review the failed inspection item.
4. Click **Create Work Order**.
5. Review the inspection details.
6. Click **Save**.

---

## Create a Work Order from PM service

Use this option when scheduled preventive maintenance is due.

1. Navigate to **PM Services**.
2. Open the due PM service.
3. Click **Create Work Order**.
4. Review the service details.
5. Assign mechanics if required.
6. Click **Save**.

---

## Create an External Work Order using AI Scan

AI Scan helps create External Work Orders from uploaded or scanned documents.

1. Navigate to **Work Orders**.
2. Click **Scan Work Order**.
3. Upload or scan the repair order, invoice, or Work Order document.
4. Fixyee AI extracts the Work Order details.
5. Review the extracted information.
6. Click **Save**.

:::tip 
<span style={{ color: '#2563eb', fontWeight: 'bold' }}>
AI Work Order Scan
</span>
AI Scan is used to create External Work Orders from uploaded or scanned repair documents.
:::

## Create an External Work Order from forwarded email

You can forward vendor or repair shop emails to Fixyee to create External Work Orders.

1. Forward the vendor or repair shop email to Fixyee.
2. Fixyee reads the email content.
3. The system creates an External Work Order automatically.
4. Review the Work Order details.
5. Save or update the Work Order if required.

:::tip
<span style={{ color: '#2563eb', fontWeight: 'bold' }}> 
Email-to-Work Order
</span>

Forwarded emails can automatically create External Work Orders and reduce manual data entry.
:::

## Add details to a Work Order

A Work Order can include multiple cost and activity details.

### Tasks

Add one or more tasks to describe the work that needs to be completed.

### Parts

Add multiple parts to a task and specify the quantity used.

### Labor

Add labor entries to track work performed and labor costs.

### Miscellaneous charges

Add charges such as shop supplies, towing fees, disposal fees, or other service-related costs.

### Mechanic time

Assign mechanics and track the time spent by each mechanic on the Work Order.

:::info
A single Work Order can include multiple tasks, parts, labor entries, miscellaneous charges, and mechanic time records.
:::

---

## Delete a Work Order

1. Navigate to **Work Orders**.
2. Locate the Work Order you want to delete.
3. In the **Actions** column, click the **three-dot menu (⋮)**.
4. Select **Delete**.
5. Confirm the deletion.

:::warning
Deleting a Work Order is permanent and cannot be undone.
:::
