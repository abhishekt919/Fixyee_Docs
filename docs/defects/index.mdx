# Defects

The Defects module helps you track, manage, and resolve issues reported on assets.

<Admonition type="info" title="What are Defects?">
Defects can be reported through inspections or created manually by users.
</Admonition>

## Features

- Create defects
- Assign defects to assets
- Filter defects by status
- Create work orders from defects
- Track defect resolution

## Defect Workflow

```text
Inspection → Defect Created → Review → Work Order → Repair → Resolved
```

## Available Topics

- Create a Defect
- Manage Defects
- Create Work Order from Defect
- Resolve Defects
