# Create a Defect

<Tabs>
  <TabItem value="manual" label="Manual Creation" default>

1. Navigate to **Defects**.
2. Click **Create Defect**.
3. Select the asset.
4. Enter defect details.
5. Click **Save**.

  </TabItem>

  <TabItem value="inspection" label="From Inspection">

1. Complete an inspection.
2. Mark an item as failed.
3. Submit the inspection.
4. A defect is automatically created.

  </TabItem>
  <TabItem value="mobile" label="Mobile">
  1. Tap on + icon.
  2. Add defect title, select customer, select asset. 
  3. Tap on Submit.
  </TabItem>
</Tabs>
:::tip
<span style={{ color: '#2563eb', fontWeight: 'bold' }}>
  Voice Defect Creation
</span>
<br />
You can create defects using voice input on both the Web and Mobile applications. Simply tap or click the microphone icon and describe the defect in your preferred language. The system will automatically convert your speech into a defect report.
:::
