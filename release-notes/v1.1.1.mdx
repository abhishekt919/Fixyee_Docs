## 🧾 Bill Reference Update Control

<div className="releaseSection">

<p>
  A new <strong>"Affect ALL EXISTING Bill Reference"</strong> checkbox
  has been added to the global PO upload process.
</p>

<ul>
  <li>
    <strong>Checkbox unchecked:</strong> The uploaded PO reference will
    only be applied where a Bill Reference does not already exist.
    Existing Bill References will remain unchanged.
  </li>
  <li>
    <strong>Checkbox checked:</strong> The uploaded PO reference will
    replace the existing Bill Reference for all applicable records.
  </li>
</ul>

:::info
By default, existing Bill References are protected from being overwritten.
Enable <strong>"Affect ALL EXISTING Bill Reference"</strong> when you
want to replace existing Bill References.
:::

</div>
